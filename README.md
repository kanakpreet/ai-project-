# HireSense AI — Job Matching & Career Agent

HireSense AI is a portfolio MVP for semantic job discovery and personalised candidate-job matching. It demonstrates embeddings, semantic retrieval, ranking, a retrieval-grounded career assistant, structured API responses and optional LLM tool calling.

> **Honest project scope:** The repository ships with a small illustrative job dataset and local SQLite database so it can run without paid services. Sentence Transformers generates local embeddings by default. If `OPENAI_API_KEY` is configured, the career assistant can use an LLM and a `search_jobs` tool. Without a key, it falls back to retrieval-based explanations. This is a portfolio prototype, not a production hiring system.

## Features

- Natural-language job search using sentence embeddings and cosine similarity.
- Candidate-job recommendations from pasted resume text.
- Ranking that can blend semantic relevance with explicit skill overlap.
- Location filtering and visible matched/missing skills.
- RAG-style answer flow: retrieve relevant indexed jobs, then ground the assistant response in retrieved records.
- Optional LLM function/tool calling to search the job index.
- API documentation generated by FastAPI at `/docs`.
- Browser demo at `/`.

## Architecture

1. Job records are stored in SQLite for the local demo.
2. Job descriptions are converted into embeddings with `sentence-transformers/all-MiniLM-L6-v2`.
3. Search queries and resume text are embedded and compared with indexed jobs using cosine similarity.
4. Results are ranked and returned with match scores and skill gaps.
5. The agent retrieves job records before answering; with an API key, it can call the `search_jobs` tool.

For a larger deployment, replace SQLite with PostgreSQL + pgvector and add authentication, ingestion pipelines, background indexing, monitoring and evaluation datasets.

## Run locally

Requires Python 3.11+.

```bash
git clone https://github.com/YOUR_USERNAME/hiresense-ai.git
cd hiresense-ai
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
uvicorn app.main:app --reload
```

macOS/Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload
```

Open `http://127.0.0.1:8000` for the UI and `http://127.0.0.1:8000/docs` for API docs. The first run may download the Sentence Transformers model. To run without it, set `USE_SENTENCE_TRANSFORMERS=false` in `.env` (this uses a simple token-vector fallback, not semantic embeddings).

## Enable LLM tool calling (optional)

Add your key to `.env`:

```env
OPENAI_API_KEY=your_key_here
OPENAI_MODEL=gpt-4o-mini
```

Restart the server. Never commit `.env` or expose API keys in frontend code.

## API examples

### Search jobs

```bash
curl -X POST http://127.0.0.1:8000/search -H "Content-Type: application/json" -d '{"query":"Python backend role with APIs and SQL","skills":["Python","SQL"],"location":"Gurugram","limit":5}'
```

### Recommend from resume text

```bash
curl -X POST http://127.0.0.1:8000/recommend -H "Content-Type: application/json" -d '{"resume_text":"Computer science student with Python, SQL, REST API, React and machine learning project experience","limit":5}'
```

### Ask the career agent

```bash
curl -X POST http://127.0.0.1:8000/agent/ask -H "Content-Type: application/json" -d '{"question":"Which jobs match my experience and what skills should I improve?","resume_text":"Python, SQL, REST APIs, PostgreSQL, React, conversational AI"}'
```

## Add a job

Use `POST /jobs` with JSON:

```json
{
  "title": "Backend Engineering Intern",
  "company": "Example Co",
  "location": "Gurugram, India",
  "skills": ["Python", "FastAPI", "SQL"],
  "description": "Build APIs and database-backed backend services."
}
```

## Evaluation ideas

Before claiming recommendation quality, create a labelled test set of candidate profiles and relevant jobs. Measure Precision@K, Recall@K and NDCG@K; compare keyword search against embedding search; inspect false positives; and track latency. Do not claim an accuracy percentage without running this evaluation.
